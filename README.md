# SORANOWA INTERIOR — demo-architecture1

架空の「株式会社ソラノワ内装」を題材にした住宅内装デザインデモ。実在企業の会社情報・住所・電話番号は掲載していません。

公開URL: https://onebe-inc.github.io/demo-architecture1/

## デザイン

6つのサービスすべてを、住宅の生成写真・オフホワイト・黒い大文字見出し・ライム色のアクセントで統一。分解図や抽象グラフィックは使用していません。

- 軽天工事
- 天井内装仕上げ
- 壁張り工事
- 間仕切り工事
- 防音工事
- 畳・ふすまの工事

見出し、説明文、詳細リンクは通常の文書フローで並べ、文字同士が重ならない構造です。PCは横スクロール、899px以下は縦スクロール。小さな画面では各セクションの高さを確保し、スクロールして全文を読めます。

## 実行・公開

Node.js 18以上で `npm start`。依存パッケージやビルドは不要。GitHub Pagesはmain / rootから自動公開されます。

## 操作

サービスのタブ・進捗スライダー・次へボタン・ホットスポットから操作できます。メインにフォーカスし、PCは左右キー、モバイルは上下キーで移動。Home / End、Escapeでのダイアログ終了、動きを減らす設定に対応しています。

## 素材

写真は生成画像であり、実際の施工事例ではありません。Anton / Noto Sans JP は SIL Open Font License。ライセンスはassets内に同梱しています。フォーム送信、個人情報の収集、アクセス解析はありません。
